# Email Sequence Writer

## 1. Pick the sequence type

| Type | Goal | Typical length |
|---|---|---|
| Welcome | Deliver what was promised, build trust | 3–5 emails over 7–10 days |
| Onboarding | Get the user to the first "aha" moment | 4–6 emails tied to actions |
| Nurture | Educate until ready to buy | 5–7 emails, weekly |
| Launch | Drive sales in a window | 4–6 emails over 7 days |
| Win-back | Re-engage inactive users | 2–3 emails |

## 2. Plan first, then write

## 3. Writing rules
- **One email = one job = one CTA.**
- Subject line ≤ 45 characters; preview text 40–90 characters and adds new info (never repeats the subject).
- Open with the reader, not with "We". First line must earn the second.
- Short paragraphs (1–3 lines); write at grade 6–8.
- Plain-text style by default — it lands in the inbox more often and feels personal.
- P.S. lines are allowed for a secondary point.
- Never invent testimonials, results or deadlines. Use `[REAL QUOTE HERE]` placeholders.
- Every email needs an unsubscribe line and the sender's real identity (GDPR / CAN-SPAM).
