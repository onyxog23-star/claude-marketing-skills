# Ad Copy Variants

## Inputs
Ask for anything missing: product/offer, audience, single goal (clicks, sign-ups, purchases), landing page URL, platform(s), budget level (to size the test), any claims that are legally restricted.

## Character limits (hard rules – count them)

| Platform | Field | Limit |
|---|---|---|
| Google Search (RSA) | Headline | 30 chars (write 10–15) |
| | Description | 90 chars (write 4) |
| Meta | Primary text | 125 chars visible before "See more" |
| | Headline | 40 chars recommended |
| | Description | 30 chars recommended |
| LinkedIn | Intro text | 150 chars visible |
| | Headline | 70 chars recommended |

Show the character count next to every line, e.g. `Learn Mizo in 10 minutes a day (31)` — and fix anything over the limit.

## Angles

Write each variant from a different angle so the test teaches you something:
1. **Outcome** – what life looks like after
2. **Pain** – the problem it removes
3. **Curiosity / hook** – a surprising fact or question (must be true)
4. **Proof** – only if the user supplied real proof
5. **Offer** – price, free trial, deadline (only real ones)

## Rules
- No fake urgency ("only 3 left") or invented stats.
- Follow platform policies: no personal-attribute targeting language ("Are you depressed?"), no before/after body claims, no misleading buttons.
- Match the landing page headline in at least one variant (message match).

## Output
1. Table per platform with variant, angle and character counts.
2. **Test plan**: which 2–3 variants to run first, what metric decides the winner (CTR for hooks, CVR for offers), and a minimum of ~1,000 impressions per variant before judging.
