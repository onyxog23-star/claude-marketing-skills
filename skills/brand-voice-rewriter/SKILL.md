# Brand Voice Rewriter

## Step 1 – Get or build the voice profile

If the user has a brand guide, read it and extract a profile. If not, build one by asking (or inferring from 2–3 samples of copy they like):

```
VOICE PROFILE
Brand:            
Audience:         
We sound like:    3 adjectives (e.g. warm, clear, encouraging)
We never sound:   3 adjectives (e.g. salesy, academic, cute)
Reading level:    e.g. grade 7
Person:           "you/we" or third person
Sentence length:  short / mixed
Words we use:     
Words we avoid:   
Emoji:            none / sparing / yes
```

Show the profile to the user once so they can correct it. Reuse it for the rest of the conversation.

## Step 2 – Rewrite

Rules:
- **Keep the meaning.** Never add facts, numbers, claims, quotes or promises that were not in the original.
- Keep required elements: product names, prices, legal lines, links, CTAs.
- Respect the channel length (see table).
- Cut filler: "in order to", "very", "really", "we are excited to announce".
- Prefer active voice and concrete verbs.

| Channel | Target length |
|---|---|
| Instagram caption | 80–150 words, hook in first line |
| LinkedIn post | 100–200 words, line breaks every 1–2 sentences |
| Email subject | ≤ 45 characters |
| Web hero | headline ≤ 10 words, sub ≤ 25 words |
| Push / SMS | ≤ 120 characters |

## Step 3 – Output format

1. **Rewritten version** (ready to paste)
2. **What changed** – 3–5 bullets (e.g. "Swapped jargon 'leverage' for 'use'")
3. **Optional alternative** – a bolder or softer variant, labelled

If the original contains something that clashes with the voice and can't be fixed by rewriting (e.g. an unverifiable claim), flag it instead of silently changing it.
