# Social Carousel Writer

## Inputs
Topic, audience, goal (save, share, follow, click), platform, number of slides (default 7), brand colours/fonts if any.

## Slide formula (7 slides)

| Slide | Job | Copy rule |
|---|---|---|
| 1 – Hook | Stop the scroll | ≤ 8 words. Promise, number or bold claim (true). |
| 2 – Problem / context | Make them nod | ≤ 25 words |
| 3–5 – Value | One idea per slide | Title ≤ 6 words + ≤ 25 words body |
| 6 – Recap / proof | Make it saveable | Checklist or summary |
| 7 – CTA | One action | "Save this", "Follow for…", or "Link in bio" |

## Rules
- One idea per slide. If it needs more words, it needs another slide.
- Big text: design for reading on a phone at arm's length.
- Every slide must make sense alone (people screenshot single slides).
- Keep a visual thread (same layout, numbered slides, progress cue "→").
- No invented stats or quotes; cite the source on the slide if you use a number.

## Sizes
- Instagram: 1080 × 1350 px (4:5)
- LinkedIn: 1080 × 1350 px, upload as PDF for document carousel

## Output
For each slide:
```
Slide 3
Title:
Body:
Visual note: (layout, icon, image idea)
```
Then: **Caption** (hook line + 3–5 short lines + CTA), **Alt text** summary, and **5–10 hashtags** mixing broad and niche.
