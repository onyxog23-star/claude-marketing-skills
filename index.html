Use it with Claude

Download a skill

Grab a folder from skills/, or clone the whole repo.

git clone https://github.com/
onyxog23-star/claude-marketing-skills

Add it to Claude

Zip the skill folder and upload it under Settings → Capabilities → Skills in Claude.ai. For Claude Code, copy it into ~/.claude/skills/.

Just ask

"Build a landing page for my yoga studio." Claude picks up the matching skill and follows its rules.
