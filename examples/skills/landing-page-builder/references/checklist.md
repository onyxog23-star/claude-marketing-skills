# Pre-delivery checklist

## Copy
- [ ] Headline states an outcome the audience wants
- [ ] One primary CTA, same wording everywhere
- [ ] No invented testimonials, numbers, ratings or logos
- [ ] Every section answers "why should I care?"
- [ ] No spelling mistakes; brand name spelled consistently

## Design
- [ ] Hero + CTA visible on a 360px-wide phone without scrolling
- [ ] Body text ≥ 16px, line length ≤ 75 characters
- [ ] Text contrast passes WCAG AA
- [ ] Consistent spacing scale (e.g. 8 / 16 / 24 / 48 / 96px)
- [ ] Max two font families

## Technical
- [ ] `<title>` and meta description filled in
- [ ] Open Graph title, description, image
- [ ] One `<h1>`, logical heading order
- [ ] All images have `alt`, `width`, `height`
- [ ] All links work; CTA points to the right URL
- [ ] No console errors; page works with JavaScript disabled (except optional extras)
