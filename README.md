### Landing page builder (web app)

[`builder/`](builder) is a dependency-free web app. Fill in a brief, choose a style (Clean, Bold or Warm) and an accent colour, toggle sections, and preview on desktop or mobile. Then download a single, responsive HTML file.

- Live preview with desktop/mobile toggle
- Automatic WCAG contrast check on the accent colour and button text
- SEO and Open Graph meta tags generated for you
- All user input HTML-escaped
- No build step, no frameworks: one HTML file

## Principles

Every skill follows the same rules:

1. **Never invent proof.** No fake testimonials, statistics, ratings, logos or urgency. Missing proof gets a clearly marked placeholder.
2. **Plan, then write.** Skills confirm the brief or plan before producing long output.
3. **Platform limits are hard rules.** Character counts, image sizes and accessibility minimums are checked, not guessed.
4. **Explain the output.** Each skill ends with what changed, what was assumed, and what to test next.

## How to use

**Claude.ai / Claude app**
1. Download or clone this repo.
2. Zip a skill folder (for example `skills/landing-page-builder`).
3. Upload it under **Settings → Capabilities → Skills**.
4. Ask naturally: *"Build a landing page for my bakery's new pre-order service."*

**Claude Code**
```bash
git clone https://github.com/onyxog23-star/claude-marketing-skills
cp -r claude-marketing-skills/skills/* ~/.claude/skills/
```
